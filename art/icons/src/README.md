# Icon kit - authoring rules (docs/ART_DIRECTION.md sections 6 and 12)

`*.svg` here + `../manifest.json` are the source of truth. `node scripts/build-icons.js` writes `www/js/icons.js` (never edit it).
Other commands: `--check` (stale/validate, CI), `--selftest` (runtime unit tests), `--list` (what is drawn / still to draw).
Review sheet: `node tests/icon-sheet.js out.png [id-prefix] [--sizes=16,24,32,44,64,96] [--dpr=2] [--ud] [--bbox] [--only=a,b]`.

## Files
One file per family (`cur.svg`, `rule.svg` ...) holding only `<symbol id="ic-<set>-<name>" viewBox="0 0 32 32">` elements and XML
comments (one comment per symbol: motif + token roles). Containers are `ct-*`. `containers.svg` and `p1-charges.svg` are generated by
`tools/gen_kit.py`: change the script, not the files. Every new id goes into `manifest.icons` (family, motif, size S|M|L, draw) and,
when it replaces an emoji, into `manifest.map`; data-driven sites (rules, perks, heroes ...) go into `manifest.by`.

## Construction (u = 1/32 of the symbol)
- Live area 28u: fill geometry inside 4..28 so the 4u ink contour ends inside 2..30 (`--bbox` flags strays). Centre the art.
- Layers bottom to top: body `class="ik"` (ink contour painted under the flat fill) / one hard shade shape bottom-right `class="hs"`
  (body minus the body shifted up-left ~2.3u, baked) / details / one charge / ivory tick `class="tk"` (1.5u, top-left).
- Details: `il` thin ink line 1.8u (vanishes when underdrawn), `ia` solid ink area, `ij` contour of a filled sub-shape (2.4u, stays).
- Flat pigment: max 3 fills + ink, written `style="fill:var(--c1,#22409A)"` (c1 body, c2 shade, c3 charge/detail) so states recolour.
  Gold (--orp #E9B62A, hard shade --bole #8C3520: gold leaf over red bole) only for precious things. Palette: docs/ART_DIRECTION.md section 2, no off-palette invention.
- Seeded wobble 0.2-0.4u baked into the coordinates (never `transform`), unequal radii, a little asymmetry: hand-cut, not geometric.
- Forbidden (build errors): gradient, filter, opacity, clipPath, mask, pattern, marker, image, text. The sprite is `display:none` and
  resources do not resolve inside it, the style is flat. Stroke only for the contour and thin inner lines, never stroke-only art.
- Sizes: S = 28u (must still read at ~14 css px; set `--tk:none` to drop the tick), M 44-64u, L 96-128u. Animals only at M >= 56u and L.
- Every shape sets its own fill/stroke: the legacy `.i{fill:none;stroke:currentColor}` rule of theme.css must not leak in.
- Class names `ik ij il ia hs tk` and tokens `--c1..3 --f1/2 --k1/2 --ink --il --tk --sw --sj --dash` are reserved for the kit (no app CSS on them).

## Composites and states
- Containers `ct-shield` (heater 3:4), `ct-round`, `ct-loz`, `ct-quat` take `--k1` field and `--k2` band (none = no band). Nest one and
  expose it as `--f1/--f2`, so the charge keeps `--c1..--c3`:
  `<use href="#ct-round" style="--k1:var(--f1,#0F1838);--k2:var(--f2,#E9B62A)"/><use href="#ic-chg-tower" x="7" y="7" width="18" height="18"/>`
- Underdrawn (locked, empty, unowned): give the `<svg>` the declarations `Z.Icons.ud` (= `--c1..3:none;--f1:none;--f2:none;--k1:none;--k2:none;`
  `--ink:var(--ud);--il:none;--tk:none;--sw:1.6;--sj:1;--dash:2 3.6`, e.g. as `.ud{...}` in theme.css) or use a manifest alias with `"state":"ud"`:
  thin dashed contour only, details and tick off. Draw nothing special for it. Gilt/owned = the plain symbol (+ `--f2` bordure on shields).
- Alias (same art, other id): manifest `"alias_of":"ic-..."`, no symbol needed; the build emits it once the target is drawn.

## Tools
`tools/pen.py` (seeded wobble, shade/tick baking; `pip install shapely`, or `PEN_PYLIB=<dir>`) and `tools/gen_kit.py` show the workflow.
Use them for a new family or hand-author; judge on the sheet at 16/24 (phone) and 96 (hand-inked) on all six grounds before wiring.
