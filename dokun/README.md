# Dokun!

Aynı telefonu paylaşan 2-4 arkadaş için hızlı mini oyunlar. Ekran oyuncu sayısına göre bölünür, üstteki oyuncular karşıdan oynar. Çoklu dokunuş desteklenir.

Mini oyunlar (9 tur, sırayla tekrar eder):
- **Tepki:** yeşil olunca ilk dokunan kazanır, erken dokunan o turdan elenir.
- **Seri Dokun:** 5 saniyede en çok dokunan kazanır.
- **Tam Ortada:** kayan topu ortadaki çizgiye en yakın durduran kazanır.

Çalıştırma: `npx serve dokun` ile aç veya `dokun/index.html` dosyasını tarayıcıda aç (telefonda yatay kilidi kapalı, dikey kullan).
